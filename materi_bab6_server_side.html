BAB 6. Menerapkan Pemrograman Server-Side

Rekayasa Perangkat Lunak (RPL)

TujuanKonsepBahasaPHPDatabaseFormDebuggingLatihan

Tujuan Pembelajaran

  1. Memahami konsep pemrograman server-side.
  2. Mengimplementasikan kode server-side untuk menangani permintaan client.
  3. Membuat aplikasi web dinamis menggunakan server-side.
  4. Mengintegrasikan database untuk menyimpan dan mengambil data.

Pendahuluan

Pemrograman web terdiri dari client-side dan server-side. Server-side mengolah data di sisi server sebelum dikirimkan ke browser. Server-side digunakan untuk membuat web dinamis seperti formulir pendaftaran, login, dan pengelolaan database. Bahasa yang umum digunakan adalah PHP, Python, Node.js, Ruby, dan Java.

1. Konsep Pemrograman Server-Side

a. Apa itu Server-Side?

Server-side adalah bagian aplikasi web yang dijalankan di server. Permintaan pengguna diproses server, kemudian hasilnya dikirim kembali ke browser.

b. Proses Permintaan dan Respons

  1. Client Request: pengguna mengirim permintaan melalui browser.
  2. Server Processing: server memproses data, mengambil database, atau melakukan perhitungan.
  3. Response: server mengirim hasil berupa HTML, JSON, atau format lain.

2. Pengantar Bahasa Server-Side

  • PHP: membuat aplikasi web dinamis.
  • Python (Django, Flask): pengembangan web modular.
  • Node.js (JavaScript): JavaScript di server, cocok untuk real-time.
  • Ruby (Ruby on Rails): framework untuk memudahkan pengembangan web.

3. Membuat Program Server-Side Menggunakan PHP

a. Struktur Dasar PHP

File PHP berakhiran .php, dijalankan di server, dan kode diawali <?php.

<?php
echo "Hello, world!";
?>

b. Mengambil Input Pengguna

HTML Form:

<form action="proses.php" method="POST">
 Nama: <input type="text" name="nama">
 <input type="submit" value="Kirim">
</form>

Proses PHP (proses.php):

<?php
if ($_SERVER["REQUEST_METHOD"] == "POST") {
  $nama = $_POST['nama'];
  echo "Nama Anda adalah: " . $nama;
}
?>

4. Menyambungkan Web dengan Database

a. Konsep Database

Database menyimpan data pengguna seperti nama dan email. PHP dapat terhubung ke MySQL dan menjalankan query.

1. Membuat koneksi

<?php
$conn = new mysqli("localhost", "root", "", "database_siswa");
if ($conn->connect_error) {
  die("Koneksi gagal: " . $conn->connect_error);
}
?>

2. Menampilkan data

<?php
$sql = "SELECT id, nama FROM siswa";
$result = $conn->query($sql);
if ($result->num_rows > 0) {
  while ($row = $result->fetch_assoc()) {
    echo "ID: " . $row["id"] . " - Nama: " . $row["nama"] . "<br>";
  }
} else {
  echo "0 hasil";
}
$conn->close();
?>

Contoh ini membutuhkan database database_siswa dan tabel siswa.

5. Menangani Formulir Pengguna

Server-side memproses data formulir dan memberikan respons. Data pendaftaran dapat disimpan ke database.

Formulir pendaftaran

<form action="daftar.php" method="POST">
 Nama: <input type="text" name="nama">
 Email: <input type="email" name="email">
 <input type="submit" value="Daftar">
</form>

Proses PHP (daftar.php)

<?php
if ($_SERVER["REQUEST_METHOD"] == "POST") {
  $nama = $_POST['nama'];
  $email = $_POST['email'];
  $conn = new mysqli("localhost", "root", "", "database_siswa");
  if ($conn->connect_error) {
    die("Koneksi gagal: " . $conn->connect_error);
  }
  $sql = "INSERT INTO pengguna (nama, email)
          VALUES ('$nama', '$email')";
  if ($conn->query($sql) === TRUE) {
    echo "Data berhasil disimpan!";
  } else {
    echo "Terjadi kesalahan: " . $conn->error;
  }
  $conn->close();
}
?>

Keamanan: Untuk aplikasi nyata, gunakan prepared statement dan validasi input agar lebih aman dari SQL injection.

6. Pengujian dan Debugging

  • Gunakan echo atau var_dump() untuk melihat nilai variabel.
  • Uji query database dengan phpMyAdmin atau SQL client.

7. Latihan Praktik

  1. Buat form login username dan password serta server-side untuk memverifikasi data.
  2. Buat aplikasi untuk menambah, melihat, dan menghapus data pengguna dalam database.

Penutup

Pemrograman server-side penting untuk membuat aplikasi web dinamis yang berinteraksi dengan pengguna dan database. Dengan memahami konsep dan teknik dasarnya, siswa dapat membuat aplikasi web yang lebih fungsional.
